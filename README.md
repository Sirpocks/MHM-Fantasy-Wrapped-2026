# Fantasy League Wrapped

A personal, non-commercial project that builds a year-end "Wrapped" style
recap for my Yahoo fantasy football league.

## What it does

- Pulls my own league's season data through the Yahoo Fantasy Sports API
  (read-only): weekly matchups, rosters, draft results, and transactions.
- Saves the data locally as CSV files.
- Calculates fun season stats with Python and pandas, such as luckiest
  team, points left on the bench, best waiver pickup, and biggest blowout.
- Presents the results to league members as an end-of-season recap.

## Data use

- Read-only access to one private league that I am a member of.
- Data is stored locally and shared only with members of that league.
- No commercial use, no ads, and no other users logging in.

## Tools

Python, pandas, and the yfpy library.

## Status

In progress. The recap will be built after the season ends.
